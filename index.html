适合谁

02 / 摄影部

活动当天。
我们在场。

跟拍、抓拍、修图。把现场的光和情绪留下来，当天出片，第二天能发。活动结束后，最先被看到的往往是照片。

一场活动的流程

提前踩点 → 全程跟拍 → 选片 → 修图 → 交付。合影和领导镜头，一定留够备份。

会用到什么

相机与镜头、补光、修图与调色软件。设备可以借，先把构图练稳。

适合谁

手稳、眼快、能在人群里找到那个瞬间的人。愿意站着拍三个小时也算。

03 / 视觉部

一张海报。
先说话。

海报、封面、活动物料。把一场活动的气质，压成一张能被停下来看的图。节气海报、招新主视觉、展板与头图，都从这里出。

一张海报的流程

定主题 → 版式 → 字体与配色 → 出图 → 多尺寸适配。先保证一眼能看懂，再谈好看。

会用到什么

设计软件、字体与素材库、一套能复用的模板。规范统一，五个部门出的图才像一家人。

适合谁

对图形和字敏感、愿意为一个间距调很久的人。会画一点点就够起步。

04 / 综合部

让其他四个部门。
只管创作。

部门日常事务、物资与场地、跨部门的排期协调。看起来是杂事，实际是让整条链路不断的那一环。

一周里的事

排班与值班、会议记录、物资清点、场地与老师对接。琐碎，但少一件就会卡住别人。

会用到什么

表格、文档、共享日历和群公告。工具普通，靠的是记得住、跟得上。

适合谁

有条理、愿意兜底、能把话说清楚的人。不爱出镜，但少了你就乱。

05 / 编辑部

一条推文。
也是一次排版。

写清楚，比写漂亮更重要。选题、文案、标题、配图的位置，都是读者能不能读下去的理由。负责推文的编排与发布，从一段活动的记录，到一条可以转发的图文。

一条推文的流程

选题会 → 采写 → 配图与排版 → 校对 → 排期发布。急稿也走这套，只是压缩时间。

会用到什么

图文编辑器、排版模板、图库与素材库。工具不难，难的是判断哪句话该留。

适合谁

爱写字、读得细、愿意为一个标题改十遍的人。写字慢没关系，肯改就行。
